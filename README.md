# Alyn's Poultry POS

A modern, offline-ready Point of Sale system built for Philippine poultry supply shops. Log sales, manage inventory, and track finances — even without internet.

## Features

- **One-tap sales logging** — Record transactions in seconds
- **Flexible pricing** — Set prices per sack or kilo with smart breakdowns
- **Works offline** — No internet? No problem. Syncs automatically when reconnected
- **Real-time dashboard** — Sales, expenses, net income, and outstanding balances at a glance
- **Inventory management** — Track stock levels, set low-stock alerts, manage categories
- **Multi-device sync** — Works across phones and tablets in the shop
